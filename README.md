# 🎯 AI Engineering & Backend Practicum — Applied Systems Track

A structured, 4-week engineering practicum repository documenting backend AI system design, model benchmarking, structured evaluation ladders, and technical architecture case studies.

---

## 📅 Practicum Roadmap & Weekly Deliverables

| Week | Track | Deliverables & Core Concepts |
| :--- | :--- | :--- |
| **Week 1** | **Sitemap & AI Toolkit** | [assignment_w1_sitemap](./assignment_w1_sitemap)<br>• Architecture sitemap design and primary CTA routing.<br>• Model benchmarking across Anthropic Claude, OpenAI, and Google Gemini.<br>• Prompt pressure-testing and prompt engineering evaluation. |
| **Week 2** | **Case Studies & Ladders** | [assignment_w2_cases](./assignment_w2_cases) & [assignment_w2_ladder](./assignment_w2_ladder)<br>• Backend persistence architectures (SQLite vs. PostgreSQL containerized stacks).<br>• Evaluation ladders: rubric-driven output quality metrics.<br>• Verification and automated test harnesses. |
| **Week 3** | **Curation & Identity** | [assignment_w3_curate](./assignment_w3_curate), [assignment_w3_identity](./assignment_w3_identity), [assignment_w3_throughline](./assignment_w3_throughline)<br>• Dataset and context window curation strategies.<br>• Persona design and system prompt guardrails.<br>• Engineering throughline documentation and narrative framing. |
| **Week 4** | **Strategic AI Decisions** | [assignment_w4_blankpage](./assignment_w4_blankpage) & [assignment_w4_threeroads](./assignment_w4_threeroads)<br>• Deconstructing open-ended AI problems ("The Blank Page").<br>• "Three Roads" trade-off analysis: fine-tuning vs. RAG vs. agentic tool use.<br>• End-to-end technical writeups and architectural post-mortems. |

---

## 🛠️ Tooling & Stack

* **Language:** Python 3.11+
* **Containerization:** Docker & Docker Compose
* **Databases:** SQLite, PostgreSQL
* **Model Platforms:** Anthropic Claude API, OpenAI API, Google Gemini API
* **Evaluation & Testing:** Pytest, Markdown rubric suites
