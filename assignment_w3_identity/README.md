# Week 3 · Assignment — Decide Once: Build Your Identity Kit

This identity kit establishes a cohesive visual design system for framing technical backend engineering projects and portfolio case studies.

---

## 🎨 Design Tokens & Palette

| Token Name | Hex Code | Role |
|---|---|---|
| **Background** | `#0f172a` | Deep Slate / Dark Mode Base |
| **Surface** | `#1e293b` | Card Container & Table Background |
| **Primary Text** | `#f8fafc` | Crisp White Body & Heading Text |
| **Accent Highlight**| `#38bdf8` | Sky Blue Interactive Links & Status Badges |

---

## 🔤 Typography

- **Heading Font:** `Outfit` (Clean, geometric modern sans-serif)
- **Body Font:** `Inter` (High-readability UI font)
- **Code Font:** `Fira Code` (Monospaced with ligatures)

## 📝 Two-Line Claude Project Style Note

```
Use slate dark mode (#0f172a background, #1e293b surface) with sky blue (#38bdf8) accents and Inter/Outfit typography.
Maintain a calm, technical mood that lets code architecture, benchmark data, and API contracts be the loudest elements on the page.
```
